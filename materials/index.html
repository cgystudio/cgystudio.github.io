PROCESS / 制作说明

从 Height 打底：手工雕痕 + Noise 走一遍 Displacement 收敛大形，再用 Tile Sampler 控制砌筑与铺装节奏；法线与粗糙度共用同一套高度信息，保证凹凸与接缝严格对齐。颜色以 Curve 收对比、以 Gradient Map 限定色域，避免全图一个灰度。最后输出 4K 四件套并回引擎校准。
