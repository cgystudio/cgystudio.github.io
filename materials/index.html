PROCESS / 制作说明

Height 打底：手工雕痕 + Noise 走 Displacement 收敛大形，Tile Sampler 控制砌筑与铺装节奏；法线与粗糙度共用同一套高度信息，保证凹凸与接缝严格对齐。颜色用 Curve 收对比、Gradient Map 限定色域，避免全图单一灰度。输出 4K 四件套后回引擎校准。每组材质均导出球 / 立方 / 圆柱 / 平面四种原型，本页取其中最利于观察轮廓的一种。
